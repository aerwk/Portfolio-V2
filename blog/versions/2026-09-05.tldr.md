# September 5, 2026

A NAS storage pool going read-only took down four separate-looking services at once: a home automation VM, a container, a backup datastore, and a backup target. A scrub ruled out the assumed cause and found isolated file damage instead, so every guest was evacuated to node-local storage rather than repaired in place, each restore verified rather than trusted. The pool is writable again, but its history means it's watched, not called fixed.
