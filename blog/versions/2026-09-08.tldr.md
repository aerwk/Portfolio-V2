# September 8, 2026

A commit hook, a design source folder and a redesign preview each lived in exactly one place. Today all three got a second copy: the hook became tracked source with a symlinked install, the design folder got its own private git repo, and the redesign shipped as a `/dev/v3` preview whose generator fails its own build on an unprefixed link.
